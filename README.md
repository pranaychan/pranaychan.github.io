# GitHub Pages Portfolio Template

A simple static HTML/CSS portfolio template for `YOUR_USERNAME.github.io`.

## Customise
Replace `YOUR NAME`, `YOUR_USERNAME`, `YOUR_EMAIL`, project details, skills and social links in `index.html`.

## Deploy
1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. Put `index.html` and `style.css` in the repository root.
3. Push to GitHub.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, `main`, `/ (root)`.
6. Save.

No build step is required.
