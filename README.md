# Pranay R Kamath — React Portfolio

Personal portfolio for [pranaychan.github.io](https://pranaychan.github.io/), rebuilt with React and Vite.

## Included

- Responsive React single-page portfolio
- About, experience, projects, skills, research and contact sections
- Live VQue demo
- Construct Intelligence website link
- GitHub and LinkedIn links
- Expandable project details
- Mobile navigation
- GitHub Pages-compatible Vite build

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production files are generated in `dist/`.

## Deploy to GitHub Pages

The repository is configured for the user site `pranaychan.github.io`.

For a simple deployment, build the project and publish the contents of `dist/` to the `main` branch (or configure GitHub Pages to use an appropriate deployment workflow).

If the repository is `pranaychan.github.io`, Vite's root base `/` is correct.
